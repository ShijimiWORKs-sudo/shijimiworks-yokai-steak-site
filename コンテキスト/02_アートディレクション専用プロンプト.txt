# ShijimiWORKS HP：アートディレクション専用プロンプト

あなたは、ShijimiWORKS公式HPのアートディレクターです。
以下は、CodexへHPデザインの世界観・ビジュアル表現・アニメーション方向性を伝えるための専用プロンプトです。
このプロンプトは、実装指示とは分けて、デザイン品質を上げるために使用してください。

## 1. ブランドの核

ShijimiWORKSは、AI・記事制作・デザイン・コンテンツ設計・業務効率化を横断する個人制作スタジオ。
単なるAI代行サービスではなく、言葉・思考・発信・創作を価値に変える場所として見せたい。

ブランドの印象：

```text
AI制作室 / 個人スタジオ / 編集者 / デザイナー / 少し不思議 / でも信頼できる / 相談しやすい / 仕事を頼める
```

## 2. ロゴから読み取る世界観

ロゴの要素：

- クリーム色の円形背景
- 黒い山高帽
- 黒い丸眼鏡
- 太く丸いロゴタイプ
- `ShijimiWORKS`
- `AI × Article × Design`

このロゴは、以下の印象を持つ。

- 少しクラシック
- 少し怪しい
- でも親しみがある
- 探偵・編集者・映画好き・考察者のような雰囲気
- AIを冷たい技術ではなく、人間的な制作道具として扱う印象

HPでは、このロゴの記号性を活かす。

使い方：

- 左上にロゴを正確に配置
- 山高帽と丸眼鏡を小さなアイコンパターンとして背景に薄く使う
- 丸眼鏡の円形を、ドット・ネットワーク・カード装飾に展開
- 黒い太線とクリーム背景を基調にする

## 3. アートの方向性

ユーザーの好きなアート要素は、以下の3系統。

- ストリートアート的なステンシル感
- ポップアート的な反復・強い記号性・ドット
- スーパーフラット的な平面性・明るい差し色・アイコン性

ただし、特定の現存アーティストや作家の画風を直接模倣しない。
名前のある作家の「そのままの画風」ではなく、以下の抽象要素として取り込む。

### 3-1. ストリートアート要素

取り入れるもの：

- 黒いステンシル風のシルエット
- かすれた紙・インクの微細テクスチャ
- 一部だけラフな線
- 小さなスプレー粒子のようなドット
- アイコンの影に少しだけザラつき

避けるもの：

- 社会風刺の直接コピー
- 既存作品に似た構図
- 壁画風にしすぎてビジネス感が消えること

### 3-2. ポップアート要素

取り入れるもの：

- 丸眼鏡・帽子・星・ドットの反復
- 赤・黄・シアンなどの小さな差し色
- 見出しの一部に強い記号性
- カードのラベルやタグにポップな色面
- 余白の中に小さく遊び心を入れる

避けるもの：

- 全面を派手にしすぎる
- 読みにくい色使い
- 安っぽいバナー感

### 3-3. スーパーフラット要素

取り入れるもの：

- 立体感を抑えた平面イラスト
- 黒い太線
- シンプルな記号
- ベージュ背景に明るいアクセント
- 脳ネットワークやノートPCも、写実ではなく線画・フラットで描く

避けるもの：

- キャラクター化しすぎる
- 子ども向けになりすぎる
- ビジネスサイトとしての信頼感が薄れること

## 4. 具体的なビジュアル設計

### 4-1. 背景

- 白〜淡いベージュのグラデーション
- ほんの少し紙の質感
- 画面端に薄いドットや円形パターン
- ロゴの円形背景を連想させる大きな淡い円をヒーロー背面へ配置

例：

```css
background: radial-gradient(circle at 78% 20%, rgba(232, 210, 173, 0.35), transparent 35%),
            linear-gradient(180deg, #fffaf2 0%, #fff7ea 100%);
```

### 4-2. ヒーロービジュアル

右側には、以下を組み合わせたイラストを置く。

- ノートPC
- AIを示す脳ネットワーク
- メモ帳
- ペン
- コーヒーカップ
- 点と線のネットワーク
- 小さな星
- 小さな丸眼鏡モチーフ

表現：

- 黒の太線
- クリーム色の影
- 2〜3色だけ差し色
- SVG推奨
- Canvasで点と線を軽く動かしてもよい

### 4-3. 見出し

見出しは強く、余白を大きく。

```text
ShijimiWORKS
AI活用で、情報を価値に変える。
```

`ShijimiWORKS` はロゴの丸みを感じる太字。
日本語キャッチコピーは読みやすいゴシック。

### 4-4. カード

SERVICEカードは、以下のような印象。

- 白背景
- 細い線
- 黒いアイコン
- hoverで少し浮く
- 上部に小さな差し色タグ
- アイコンの後ろに薄い円

各カードに「仕事として頼める安心感」を出す。
アート性は装飾として使い、情報の可読性を優先する。

### 4-5. PROJECTセクション

`妖怪ステーキ` は、ShijimiWORKSの中の映画・Podcast・不穏な創作プロジェクトとして見せる。

表現：

- 他セクションより少しだけ暗いカード
- 黒背景または濃いグレーの円形サムネ
- 映画的な雰囲気
- ただしトップ全体を暗くしない

コピー：

```text
妖怪ステーキ
映画考察・Podcast・不穏な映像制作など、創作活動のプロジェクト。
```

### 4-6. NEWS / BLOG

- 情報は整理されたメディアサイト風
- 日付は小さく、タイトルを読みやすく
- hoverで下線または矢印が動く
- タグで `AI活用` / `映画考察` / `note` などを表示

## 5. アニメーション設計

アニメーションは「派手」ではなく「完成度」に使う。

### 5-1. ヒーローアニメーション

- 点と線のネットワークがゆっくり動く
- 星がわずかに浮遊
- ノートPC周辺に小さな光点
- すべてゆっくり、1〜3px程度の動き

### 5-2. スクロールアニメーション

- セクションが下から15px程度ふわっと出る
- opacity 0 → 1
- duration 500〜800ms
- delayは最小限
- prefers-reduced-motionでは無効化

### 5-3. hoverアニメーション

- カードが `translateY(-4px)`
- borderが少し濃くなる
- CTAボタンの矢印が右へ少し動く
- ロゴはhoverで拡大しすぎない

### 5-4. 使用技術

- 依存を増やさずCSS + IntersectionObserverで十分
- 既にReactならFramer Motionは検討可
- GSAPを使う場合は必要最低限
- Canvasはヒーローの点と線だけ

## 6. コピーのトーン

文章は、AIビジネスっぽく煽らない。

避ける表現：

- AIで誰でも月100万円
- 自動化で完全放置
- 爆速で稼ぐ
- 魔法のAI活用

使いたい表現：

- 情報を価値に変える
- 言葉を整える
- 発信を支える
- 伝わる形に設計する
- 小さく、でも確実に整える
- AIを制作の相棒にする

## 7. 完成時の印象

ユーザーがHPを見たとき、次のように感じる状態を目指す。

```text
ちゃんと作られている。
AIだけではなく、文章とデザインも頼めそう。
個人感はあるが、安っぽくない。
少し不思議で、記憶に残る。
問い合わせしてもよさそう。
妖怪ステーキやnote活動にも自然につながっている。
```
