## 5. リンク設定方針

リンクは適当に設定しないこと。
まずHPproject内の既存HTML、JS、JSON、Markdown、環境ファイルから実URLを検索する。

検索キーワード：

```text
note
substack
youtube
youtu.be
podcast
spotify
stand.fm
apple
x.com
twitter
threads
tiktok
coconala
crowdworks
lancers
contact
mailto
妖怪ステーキ
ShijimiWORKS
```

リンク方針：

| 表示名 | 優先リンク | 見つからない場合 |
|---|---|---|
| HOME | `/` または `#home` | `#home` |
| ABOUT | `/about` または `#about` | `#about` |
| SERVICE | `/service` または `#service` | `#service` |
| WORKS | `/works` または `#works` | `#works` |
| BLOG | 既存ブログURL / note / Substack | `#blog` |
| CONTACT | 既存メール / フォーム / ココナラ | `#contact` |
| 制作を相談する | CONTACT or ココナラ | `#contact` |
| 妖怪ステーキを見る | 妖怪ステーキ関連URL | `#project-youkai` |
| Note | noteの実URL | TODOコメント付き `#note` |
| Podcast | 実Podcast URL | TODOコメント付き `#podcast` |
| YouTube | 実YouTube URL | TODOコメント付き `#youtube` |
| TikTok | 実TikTok URL | TODOコメント付き `#tiktok` |
| Blog | 実Blog/Substack URL | TODOコメント付き `#blog` |

重要：
実URLが見つからない場合、適当なURLを作らない。必ずTODOとして残す。

## 6. 技術要件

既存プロジェクトの技術構成を優先する。

### 6-1. 既存がVite / React の場合

- Reactコンポーネント分割
- CSS Modules または通常CSSで整理
- assetsディレクトリに画像配置
- npm scriptsで起動確認

### 6-2. 既存がNext.jsの場合

- app router / pages router の構成を崩さない
- コンポーネント分割
- 画像最適化
- meta情報設定

### 6-3. 既存がHTML/CSS/JSのみの場合

- 無理にReact化しなくてよい
- ただし、構造を整理し、main.css / main.js に分ける
- Node.jsは開発サーバー・ビルド・検証で使用できるようにする

### 6-4. Node.js / JavaScript品質

Node.jsやJavaScriptを活用して、静的なだけのHPではなく、完成度を上げる。

実装候補：

- Vite開発環境
- IntersectionObserverによるスクロールアニメーション
- ヒーロー右側の点と線のネットワークをCanvasまたはSVGで軽く動かす
- hover時のカード浮遊
- CTAボタンの微細なアニメーション
- スクロール進行に応じたヘッダー変化
- prefers-reduced-motion対応
- 画像遅延読み込み
- レスポンシブ最適化
- Lighthouseの基本対策

注意：
重すぎるアニメーションや、意味のない派手な演出は不要。上品で、見た瞬間に「ちゃんと作られている」と分かる完成度を目指す。

## 7. アニメーション方針

### 入れてよい動き

- ヒーロー右側のネットワークの点がゆっくり浮遊
- ノートPC周辺の小さな星・ドットが微かに動く
- スクロールでセクションがふわっと表示
- サービスカードのhover時に少し浮く
- ボタンhoverで矢印や影が動く
- Headerがスクロール時に半透明ブラー化

### 入れてはいけない動き

- 文字が読みにくくなる過剰なアニメーション
- 点滅
- 画面全体が重くなる演出
- 初回表示に時間がかかる演出
- スマホで操作を邪魔する演出

## 8. アートディレクション

ユーザーの好きなアート要素：

- ストリートアート的なステンシル感

完成イメージ：

```text
日本語ミニマル × AI制作スタジオ × ポップアートの軽い遊び心 × 仕事を頼める信頼感
```

## 9. フォント・配色

### フォント

候補：

- 英字ロゴ・見出し：丸みのある太字系。Google Fonts使用可なら `Nunito Sans`, `Fredoka`, `Inter`, `Zen Maru Gothic` などを検討
- 日本語本文：`Noto Sans JP`, `Zen Kaku Gothic New`, system-ui
- 過度に子供っぽくしない
- ロゴの雰囲気は丸く、本文は読みやすく

### 配色

ベース：

```text
background: #fff7ea / #fffaf2 / #f6ead8
text: #151515
muted text: #555
accent beige: #e8d2ad
accent black: #111
line: #e0d4c2
```

差し色：

```text
pop yellow: #ffd84d
pop red: #ff4b3e
pop cyan: #4cc9f0
```

差し色は使いすぎない。サービスカードや小さな記号に限定する。
