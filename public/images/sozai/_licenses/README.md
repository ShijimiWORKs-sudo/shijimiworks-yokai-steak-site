# 素材ライセンス管理メモ

このフォルダは、ShijimiWORKs / 妖怪ステーキ HPで利用候補となるフリー素材・イラスト素材の出典と利用条件を管理するためのものです。

今回は受け皿作成のみです。各サイトの利用規約は、素材を実際に保存・使用する前に必ず公式ページで再確認してください。未確認の項目は「要確認」として扱います。

## 共通運用ルール

- 素材サイトを自動大量クロールしない。
- 出典URLが不明な素材は保存しない。
- 保存した素材は `materials-index.json` と `materials-index.csv` に必ず記録する。
- 素材そのものを再配布・販売する目的で保存しない。
- ココナラ出品画像や制作実績画像に使う場合は、商用利用・加工・クレジット要否を個別確認する。
